# 1. 执行摘要

本次评估显示，finv 的分类覆盖率为 89.96%，略高于 Illion 的 89.50%，说明 finv 覆盖率基本持平于 Illion，finv 在覆盖范围上具有一定优势。在双方均给出分类的交易中，分类一致率达到 88.70%，表明两者对同一交易的分类结果整体较为一致。在存在差异的交易中，双方分类不一致占比最高，为 44.81%，仅 finv 有值占 28.69%，仅 Illion 有值占 26.50%，说明分类分歧是主要差异来源，而非单方覆盖缺失。差异交易主要集中在转账类、高频消费类及部分负债类。总体来看，finv 的核心特征是覆盖更广，但覆盖范围的扩大也引入了更多分类差异；当前主要问题并非覆盖不足，而是部分类别下双方分类规则和边界不一致。后续优化应优先聚焦转账、高频消费和部分负债类场景，推动分类标准对齐与差异治理。

# 2. 覆盖与一致全景

本部分自顶向下展示覆盖与一致情况：先看总体一致率与差异性质，再看业务板块，最后拆解到类别。覆盖率的含义是「Illion / finv 识别为某个类别的交易占总交易的比例」；一致率的含义是「双方分类一致（类别完全相同）的交易占至少一侧有分类交易的比例」。覆盖与一致的情况清楚后，第 3 章进入类别细探，各类别的全量指标明细汇总于第 4 章附录。

## 2.1 总体覆盖、一致率与差异性质

| 指标 | 数值 | 口径说明 |
| :--- | :---: | :--- |
| Illion 覆盖率 | 89.50% | Illion 有分类交易 / 总交易数 |
| finv 覆盖率 | 89.96% | finv 有分类交易 / 总交易数 |
| 覆盖差（finv − Illion） | 0.46% | finv 高于 Illion 的幅度 |
| 双方均有分类 | 83.89% | 双方分类均非空的交易 / 总交易数 |
| 双方非空一致率 | 88.70% | 类别一致 / 双方均有分类 |
| 覆盖调整后一致率 | 77.86% | 类别一致 / 至少一侧有分类 |
| 差异率（至少一侧有分类） | 22.14% | 差异总数 / 至少一侧有分类 |

在覆盖率上，finv（89.96%）较 Illion（89.50%）高出 0.46 个百分点，覆盖范围略广。全部交易中，双方均有分类的占比为 83.89%，在这部分交易内，类别一致率达到 88.70%，表明双方在共同覆盖范围内的判定结果较为一致。然而，若将仅单侧有分类的交易也纳入评价基准（即「至少一侧有分类」口径），一致率下降至 77.86%，差异率相应为 22.14%。两个口径之间的落差（相差 10.84 个百分点）源于仅单侧有分类的交易，该部分占并集（至少一侧有分类）的 12.22%；将其计入差异后，整体一致率明显走低。

进一步拆解差异构成，可区分两种性质：双方分类不一致（两侧均有分类但标签不同，反映分类规则或边界判定的分歧）与单侧识别缺失（仅一侧有分类，反映覆盖缺口）。具体分布如下：

| 差异类型 | 占差异总数 | 分析含义 |
| :--- | :---: | :--- |
| 双方分类不一致 | 44.81% | 两侧均有分类，但类别标签不同 |
| 仅 finv 有值 | 28.69% | finv 新增识别或 Illion 侧缺少分类 |
| 仅 Illion 有值 | 26.50% | finv 侧缺少分类（仅 Illion 侧识别） |
| 总差异数 | 100.00% | 分类不一致与单边缺失的合计 |

双方分类不一致占比最高（44.81%），是最大的差异来源；仅 finv 有值（28.69%）次之；仅 Illion 有值（26.50%）再次之。前两类合计贡献约 73.50% 的差异。需说明的是，双方均为空的交易（占全部交易的 4.43%）未纳入差异分析，因其不具备分类可比性。综上，finv 覆盖略优，但在共同覆盖范围内的一致性较高；整体差异主要源于分类标签分歧，其次是 finv 侧的额外识别覆盖，Illion 侧的独有识别贡献相对较小。
